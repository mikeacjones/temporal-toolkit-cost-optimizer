---
id: SIG-002
title: Start, then Signal
why_it_costs: The start and the Signal are an Action each. Signal-With-Start does both for one Action.
fix: Replace the start-then-signal pair with one Signal-With-Start call.
tradeoffs: None for most callers. Signal-With-Start also starts the Workflow when it isn't running, so check that a duplicate start can't happen by accident.

In each match, the client that started the Workflow sent it a Signal within one second of the start. That pattern costs two Actions where Signal-With-Start costs one.

Updates sent right after start aren't flagged. Update-With-Start bills the start and the Update separately, so it saves a round trip but no Actions.
