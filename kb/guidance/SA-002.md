The Workflow sends two or more upsert commands from the same Workflow Task. Temporal bills each command as one Action, so three upserts in a row cost three Actions where one would do.

Build the full set of updates first, then call the upsert once. If the values come from different helpers, have each helper return its update instead of upserting it.
