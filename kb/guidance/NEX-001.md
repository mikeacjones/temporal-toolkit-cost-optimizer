id: NEX-001
title: Nexus Operation backed by a Workflow that runs one Activity
why_it_costs: The handler Namespace pays a Workflow start on top of the Activity for every call. An Activity-backed Nexus Operation would run the Activity without the Workflow.
fix: When Activity-backed Nexus Operations are available to you, back this operation with the Activity instead of a Workflow.
tradeoffs: The feature is pre-release, so this is advisory. Keep the Workflow if the operation needs more steps later, or if callers rely on the handler Workflow's history.

This finding is about the handler side. A Nexus Operation started each matching run: the start event carries the Nexus completion callback that returns the result to the caller. The Workflow then ran one Activity and closed. The caller pays for the Nexus Operation either way. The handler Namespace pays for the Workflow start, which an Activity-backed operation wouldn't need.
