---
id: CFG-006
title: Idle Namespace
why_it_costs: A Namespace with no new Workflows still bills storage for the histories it holds.
fix: Delete the Namespace if nobody uses it.
tradeoffs: Deleting a Namespace removes its histories. Export them first if you need them.
docs:
  - kb: cost/best-practices-cost-optimization#storage-optimization
snippets:
  tcld: snippets/CFG-006.tcld.md
---

The Namespace ran no Actions in the period tcopt checked, but it still holds open or retained histories. Lowering retention only affects Workflows that close after the change, so it doesn't clear what's already stored.

With usage data, tcopt checks for days with no Actions. Without it, tcopt counts Workflow starts through Visibility.
