id: CFG-003
title: Fairness on but unused
why_it_costs: While Fairness is on, every Action in the Namespace bills an extra 0.1 Action.
fix: Turn Fairness off, or start setting fairness keys where you need them.
tradeoffs: None while no Workflow or Activity sets a fairness key. Fairness does nothing without keys.

Fairness is enabled on the Namespace, but none of the sampled histories sets a fairness key on a Workflow start, Activity, or Child Workflow. Temporal Cloud charges 0.1 Action per Action for each hour Fairness is on, whether or not anything uses it.

tcopt checks a sample of histories from the Workflow Types it analyzed. A Workflow Type outside that sample could still set keys, so check the code before turning Fairness off.
