---
id: SA-003
title: Upserts in consecutive Workflow Tasks
why_it_costs: Each upsert is an Action. When the next Workflow Task replaces a value within a couple of seconds, with no Signal or Update in between, almost no one sees the first value.
fix: Set the attributes once, at the later point.
tradeoffs: The intermediate value disappears from Visibility. Keep it if someone watches for it, for example a dashboard that counts Workflows in that state.

Each match is a run of upserts in back-to-back Workflow Tasks, each within two seconds of the last, with no Signal or Update between them. Each upsert after the first is an Action you could drop by setting the values together at the end.

The first Workflow Task is left to SA-001, and several upserts in one task are left to SA-002, so no Action is counted twice.
