---
id: SA-001
title: Search Attributes upserted at the start
why_it_costs: Each upsert is an Action. Search Attributes passed in the start options aren't billed.
fix: Pass the attributes in the start options and remove the upsert from the first Workflow Task.
tradeoffs: The caller has to know the values when it starts the Workflow. If they come from the Workflow's own logic, keep the upsert.

---

Each match upserts Search Attributes in the first Workflow Task, before any Activity, Timer, Signal, or Update could produce the values. They depend only on the input, so the caller can set them at start.

`TemporalChangeVersion`, which `GetVersion` writes, isn't billed and isn't counted. When the first task upserts several times, SA-002 counts the extra upserts.
