Before: a Timer and an Activity per check, two Actions each time.

```go
for {
	var ready bool
	if err := workflow.ExecuteActivity(ctx, CheckStatus, jobID).Get(ctx, &ready); err != nil {
		return err
	}
	if ready {
		break
	}
	if err := workflow.Sleep(ctx, time.Minute); err != nil {
		return err
	}
}
```

After: one Activity that returns an error until the job is ready. Each retry is one Action, at a fixed interval.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 30 * time.Second,
	RetryPolicy: &temporal.RetryPolicy{
		InitialInterval:    time.Minute,
		BackoffCoefficient: 1.0,
		MaximumInterval:    time.Minute,
	},
})
err := workflow.ExecuteActivity(ctx, WaitUntilReady, jobID).Get(ctx, nil)

// In the Activity: return an error while the job isn't ready.
func WaitUntilReady(ctx context.Context, jobID string) error {
	if !jobReady(ctx, jobID) {
		return errors.New("not ready yet")
	}
	return nil
}
```
