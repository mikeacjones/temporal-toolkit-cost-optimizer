Before: two Worker builds poll "orders", and only the new one registers Ship.

```go
w := worker.New(c, "orders", worker.Options{})
w.RegisterWorkflow(OrderWorkflow)
w.RegisterActivity(Charge) // the old build doesn't have Ship
```

After: Ship runs on its own Task Queue, which only Workers that register it poll.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	TaskQueue:           "orders-shipping",
	StartToCloseTimeout: time.Minute,
})
err := workflow.ExecuteActivity(ctx, Ship, order).Get(ctx, nil)

shipping := worker.New(c, "orders-shipping", worker.Options{})
shipping.RegisterActivity(Ship)
```
