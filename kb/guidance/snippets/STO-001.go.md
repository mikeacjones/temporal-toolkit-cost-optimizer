Before: the report travels through history.

```go
var report []byte
_ = workflow.ExecuteActivity(ctx, BuildReport, orderID).Get(ctx, &report)
_ = workflow.ExecuteActivity(ctx, SendReport, report).Get(ctx, nil)
```

After: the Activity stores the report and returns its key.

```go
var key string
_ = workflow.ExecuteActivity(ctx, BuildReport, orderID).Get(ctx, &key)
_ = workflow.ExecuteActivity(ctx, SendReport, key).Get(ctx, nil)
```

```go
func BuildReport(ctx context.Context, orderID string) (string, error) {
	report := build(orderID)
	key := "reports/" + orderID
	return key, blobs.Put(ctx, key, report)
}
```
