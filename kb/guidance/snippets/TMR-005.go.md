Before: the first thing the Workflow does is sleep.

```go
func FollowUpWorkflow(ctx workflow.Context, lead Lead) error {
	if err := workflow.Sleep(ctx, 24*time.Hour); err != nil {
		return err
	}
	// ... the real work
}
```

After: the caller sets a start delay, and the Workflow starts with the work.

```go
_, err := c.ExecuteWorkflow(ctx, client.StartWorkflowOptions{
	ID:         "follow-up-" + lead.ID,
	TaskQueue:  "leads",
	StartDelay: 24 * time.Hour,
}, FollowUpWorkflow, lead)
```
