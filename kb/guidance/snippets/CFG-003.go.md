Fairness only changes how tasks are dispatched when work carries a fairness key:

```go
ao := workflow.ActivityOptions{
	StartToCloseTimeout: time.Minute,
	Priority:            temporal.Priority{FairnessKey: tenantID},
}
```

If no code sets `FairnessKey`, turn Fairness off for the Namespace in the Temporal Cloud UI or through the Cloud Ops API.
