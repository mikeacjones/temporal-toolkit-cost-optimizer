Before: a large history waits a week in Active Storage.

```go
_ = processBatch(ctx, input)
_ = workflow.Sleep(ctx, 7*24*time.Hour)
return processBatch(ctx, input)
```

After: the run continues as new and the new run does the waiting.

```go
_ = processBatch(ctx, input)
input.WaitFirst = 7 * 24 * time.Hour
return workflow.NewContinueAsNewError(ctx, BatchWorkflow, input)
```

```go
func BatchWorkflow(ctx workflow.Context, input BatchInput) error {
	if input.WaitFirst > 0 {
		_ = workflow.Sleep(ctx, input.WaitFirst)
	}
	// ...
}
```
