Before: a Workflow whose only job is one Nexus Operation.

```go
func RequestQuoteWorkflow(ctx workflow.Context, req QuoteRequest) (Quote, error) {
	nc := workflow.NewNexusClient("pricing", "quotes")
	var q Quote
	err := nc.ExecuteOperation(ctx, "quote", req, workflow.NexusOperationOptions{
		ScheduleToCloseTimeout: time.Minute,
	}).Get(ctx, &q)
	return q, err
}
```

After: a standalone Nexus Operation from the client. This API is experimental in Go SDK v1.49.

```go
nc, err := c.NewNexusClient(client.NexusClientOptions{Endpoint: "pricing", Service: "quotes"})
if err != nil {
	return err
}
handle, err := nc.ExecuteOperation(ctx, "quote", req, client.StartNexusOperationOptions{
	ID:                     "quote-" + req.ID,
	ScheduleToCloseTimeout: time.Minute,
})
if err != nil {
	return err
}
var q Quote
err = handle.Get(ctx, &q)
```
