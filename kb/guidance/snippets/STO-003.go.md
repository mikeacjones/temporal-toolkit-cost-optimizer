Before: one run that never ends.

```go
func Subscription(ctx workflow.Context, s State) error {
	for {
		_ = workflow.ExecuteActivity(ctx, Bill, s.CustomerID).Get(ctx, nil)
		_ = workflow.Sleep(ctx, 24*time.Hour)
	}
}
```

After: the run continues as new when the server suggests it.

```go
func Subscription(ctx workflow.Context, s State) error {
	for {
		_ = workflow.ExecuteActivity(ctx, Bill, s.CustomerID).Get(ctx, nil)
		_ = workflow.Sleep(ctx, 24*time.Hour)
		if workflow.GetInfo(ctx).GetContinueAsNewSuggested() {
			return workflow.NewContinueAsNewError(ctx, Subscription, s)
		}
	}
}
```
