Before: a Heartbeat timeout on an Activity that finishes in a second or two. The first Heartbeat goes out at once, so every run pays one extra Action.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 30 * time.Second,
	HeartbeatTimeout:    5 * time.Second,
})
```

After: no Heartbeat timeout on short Activities. A long Activity keeps one, set to how quickly you need to notice a dead Worker.

```go
short := workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 30 * time.Second,
})

long := workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 2 * time.Hour,
	HeartbeatTimeout:    2 * time.Minute, // at most one Heartbeat Action every ~96 s
})
```
