Today: a Workflow-backed Nexus Operation whose Workflow runs one Activity.

```go
var chargeOp = temporalnexus.NewWorkflowRunOperation("charge", ChargeWorkflow,
	func(ctx context.Context, in ChargeInput, _ nexus.StartOperationOptions) (client.StartWorkflowOptions, error) {
		return client.StartWorkflowOptions{ID: "charge-" + in.OrderID}, nil
	})

func ChargeWorkflow(ctx workflow.Context, in ChargeInput) (Receipt, error) {
	var r Receipt
	err := workflow.ExecuteActivity(ctx, Charge, in).Get(ctx, &r)
	return r, err
}
```

The Go SDK v1.49 has no Activity-backed Nexus Operation handler yet, so there is no "after" snippet. When your SDK version supports it, back `charge` with the `Charge` Activity directly and remove `ChargeWorkflow`.
