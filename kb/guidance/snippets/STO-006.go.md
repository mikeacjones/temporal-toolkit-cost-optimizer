Before: a Local Activity returns the whole record, and its marker stores it.

```go
var customer Customer
_ = workflow.ExecuteLocalActivity(ctx, LoadCustomer, id).Get(ctx, &customer)
if customer.Tier == "gold" {
	// ...
}
```

After: it returns only what the Workflow uses.

```go
var tier string
_ = workflow.ExecuteLocalActivity(ctx, LoadCustomerTier, id).Get(ctx, &tier)
if tier == "gold" {
	// ...
}
```
