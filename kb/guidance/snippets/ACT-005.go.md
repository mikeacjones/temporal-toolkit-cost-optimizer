Before: three tiny steps, three Actions.

```go
var normalized Order
_ = workflow.ExecuteActivity(ctx, Normalize, order).Get(ctx, &normalized)
var priced Order
_ = workflow.ExecuteActivity(ctx, Price, normalized).Get(ctx, &priced)
var taxed Order
_ = workflow.ExecuteActivity(ctx, AddTax, priced).Get(ctx, &taxed)
```

After: one regular Activity runs the same functions, one Action.

```go
var taxed Order
_ = workflow.ExecuteActivity(ctx, PrepareOrder, order).Get(ctx, &taxed)

// PrepareOrder runs steps that share one failure boundary.
func (a *Activities) PrepareOrder(ctx context.Context, o Order) (Order, error) {
	o = normalize(o)
	o = price(o)
	return addTax(o), nil
}
```
