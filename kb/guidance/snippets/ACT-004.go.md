Before: a 2-second Heartbeat timeout on an Activity that runs for minutes sends a Heartbeat every 1.6 seconds.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 30 * time.Minute,
	HeartbeatTimeout:    2 * time.Second,
})
```

After: a 1-minute timeout sends one about every 48 seconds. The Activity code doesn't change; the SDK throttles RecordHeartbeat calls.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 30 * time.Minute,
	HeartbeatTimeout:    time.Minute,
})
```
