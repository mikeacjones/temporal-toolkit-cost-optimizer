Before: a Timer after every Signal, 1 Action each time.

```go
ch := workflow.GetSignalChannel(ctx, "update")
for {
	var u Update
	ch.Receive(ctx, &u)
	_ = workflow.Sleep(ctx, 5*time.Second) // wait for more updates
	_ = workflow.ExecuteActivity(ctx, Apply, u).Get(ctx, nil)
}
```

After: buffer whatever has arrived and apply it together.

```go
ch := workflow.GetSignalChannel(ctx, "update")
for {
	var batch []Update
	var u Update
	ch.Receive(ctx, &u)
	batch = append(batch, u)
	for ch.ReceiveAsync(&u) {
		batch = append(batch, u)
	}
	_ = workflow.ExecuteActivity(ctx, ApplyAll, batch).Get(ctx, nil)
}
```
