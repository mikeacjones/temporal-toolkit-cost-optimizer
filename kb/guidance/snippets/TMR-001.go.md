Before: a Timer and an Activity per poll, 2 Actions each time.

```go
for {
	_ = workflow.Sleep(ctx, time.Minute)
	var status string
	_ = workflow.ExecuteActivity(ctx, CheckStatus, jobID).Get(ctx, &status)
	if status == "done" {
		break
	}
}
```

After: the Activity fails until the job is done, and each retry is 1 Action.

```go
ctx = workflow.WithActivityOptions(ctx, workflow.ActivityOptions{
	StartToCloseTimeout: 10 * time.Second,
	RetryPolicy: &temporal.RetryPolicy{
		InitialInterval:    time.Minute,
		BackoffCoefficient: 1,
	},
})
err := workflow.ExecuteActivity(ctx, WaitUntilDone, jobID).Get(ctx, nil)
```

```go
func WaitUntilDone(ctx context.Context, jobID string) error {
	if status := checkStatus(jobID); status != "done" {
		return fmt.Errorf("job %s is %s", jobID, status)
	}
	return nil
}
```
