Before: a declined card is retried until the attempts run out.

```go
if resp.StatusCode == http.StatusPaymentRequired {
	return fmt.Errorf("card declined: %s", resp.Status)
}
```

After: the Activity fails at once.

```go
if resp.StatusCode == http.StatusPaymentRequired {
	return temporal.NewNonRetryableApplicationError("card declined", "PaymentDeclined", nil)
}
```

Or keep the error retryable in the Activity and stop it in the Retry Policy:

```go
RetryPolicy: &temporal.RetryPolicy{
	MaximumAttempts:        5,
	NonRetryableErrorTypes: []string{"PaymentDeclined", "InvalidArgument"},
},
```
