Before: a new run after every batch, one start each time.

```go
func PollerWorkflow(ctx workflow.Context, cursor string) error {
	next, err := pollOnce(ctx, cursor)
	if err != nil {
		return err
	}
	return workflow.NewContinueAsNewError(ctx, PollerWorkflow, next)
}
```

After: keep going in the same run until the history is large enough.

```go
func PollerWorkflow(ctx workflow.Context, cursor string) error {
	for {
		next, err := pollOnce(ctx, cursor)
		if err != nil {
			return err
		}
		cursor = next
		info := workflow.GetInfo(ctx)
		if info.GetContinueAsNewSuggested() || info.GetCurrentHistoryLength() > 2000 {
			return workflow.NewContinueAsNewError(ctx, PollerWorkflow, cursor)
		}
	}
}
```
