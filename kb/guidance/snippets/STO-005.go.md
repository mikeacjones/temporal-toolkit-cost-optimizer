Before: the run waits for the deadline even after the approval arrives.

```go
deadline := workflow.NewTimer(ctx, 7*24*time.Hour)
workflow.GetSignalChannel(ctx, "approved").Receive(ctx, nil)
_ = workflow.ExecuteActivity(ctx, Ship, orderID).Get(ctx, nil)
return deadline.Get(ctx, nil)
```

After: whichever comes first ends the run, and the Timer is canceled.

```go
timerCtx, cancel := workflow.WithCancel(ctx)
deadline := workflow.NewTimer(timerCtx, 7*24*time.Hour)
approved := false
sel := workflow.NewSelector(ctx)
sel.AddFuture(deadline, func(workflow.Future) {})
sel.AddReceive(workflow.GetSignalChannel(ctx, "approved"), func(c workflow.ReceiveChannel, _ bool) {
	c.Receive(ctx, nil)
	approved = true
})
sel.Select(ctx)
if !approved {
	return ErrExpired
}
cancel()
return workflow.ExecuteActivity(ctx, Ship, orderID).Get(ctx, nil)
```
