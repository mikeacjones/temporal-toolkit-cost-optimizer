Before: one Signal per item.

```go
for _, item := range items {
	if err := c.SignalWorkflow(ctx, cartID, "", "add-item", item); err != nil {
		return err
	}
}
```

After: one Signal with every item. The handler takes a slice.

```go
if err := c.SignalWorkflow(ctx, cartID, "", "add-items", items); err != nil {
	return err
}

// In the Workflow:
var batch []Item
workflow.GetSignalChannel(ctx, "add-items").Receive(ctx, &batch)
```
