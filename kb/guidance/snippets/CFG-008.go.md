Delete a Schedule that no longer runs:

```go
err := c.ScheduleClient().GetHandle(ctx, "nightly-report").Delete(ctx)
```

Replace the whole spec when updating, rather than appending to it:

```go
err := handle.Update(ctx, client.ScheduleUpdateOptions{
	DoUpdate: func(in client.ScheduleUpdateInput) (*client.ScheduleUpdate, error) {
		s := in.Description.Schedule
		s.Spec = &client.ScheduleSpec{CronExpressions: []string{"0 2 * * *"}}
		return &client.ScheduleUpdate{Schedule: &s}, nil
	},
})
```
