Before: one Action on every iteration, even when the status hasn't changed.

```go
_ = workflow.UpsertTypedSearchAttributes(ctx, OrderStatus.ValueSet(status))
```

After: an Action only when the value changes.

```go
current, _ := workflow.GetTypedSearchAttributes(ctx).GetKeyword(OrderStatus)
if current != status {
	_ = workflow.UpsertTypedSearchAttributes(ctx, OrderStatus.ValueSet(status))
}
```
