Before: the interceptor copies all baggage into every Activity's header.

```go
func (o *outbound) ExecuteActivity(ctx workflow.Context, activityType string, args ...any) workflow.Future {
	if h := interceptor.WorkflowHeader(ctx); h != nil {
		h["baggage"], _ = converter.GetDefaultDataConverter().ToPayload(allBaggage(ctx))
	}
	return o.Next.ExecuteActivity(ctx, activityType, args...)
}
```

After: only the trace context travels.

```go
func (o *outbound) ExecuteActivity(ctx workflow.Context, activityType string, args ...any) workflow.Future {
	if h := interceptor.WorkflowHeader(ctx); h != nil {
		h["traceparent"], _ = converter.GetDefaultDataConverter().ToPayload(traceParent(ctx))
	}
	return o.Next.ExecuteActivity(ctx, activityType, args...)
}
```
