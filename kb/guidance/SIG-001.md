---
id: SIG-001
title: Bursts of the same Signal
why_it_costs: Every Signal is an Action. A sender that sends several of the same Signal within a second could send one Signal carrying all of them.
fix: Batch the items on the sending side and send one Signal with the list.
tradeoffs: The Workflow sees the items together rather than one by one, and the sender has to hold them briefly. Don't batch when each item must reach the Workflow as soon as it exists.

Each match is three or more Signals with the same name, from the same sender identity, within one second of the first. A burst of n Signals costs n Actions; one Signal with all n items costs one.

Signals that arrive with Signal-With-Start aren't counted, because they're billed with the start.
